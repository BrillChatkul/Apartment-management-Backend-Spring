# Apartment-management-Backend-Spring

Dependency
- Spring Web
- Spring Data JPA
- PostgreSQL Driver
- Spring Boot DevTools
- Validation
- Lombok (intellij : Recommend plugin : Lombok)
- mapstruct

Environment Variables
- DB_CONNECTION_PATH : database path connection (localhost:5432/dbname)
- DB_USERNAME : username for database connection
- DB_PASSWORD : password for database connection
